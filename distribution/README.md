# JAZEKKER Distribution Layer

This folder holds channel-specific drafts and metadata for approved Orientation Objects.

Distribution is not publication. AI Cabinet may draft distribution materials, but it may not publish, send, post, schedule, or update external channels without an approval record.

Channels:

- `website/` - canonical public object or article draft.
- `newsletter/` - newsletter draft.
- `linkedin/` - LinkedIn draft.
- `telegram/` - Telegram draft.
- `rss/` - RSS metadata draft.

Distribution metadata schema:

```text
ai-cabinet/schemas/distribution-metadata.schema.json
```
