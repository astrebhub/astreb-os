# JAZEKKER - Orientation Experience UX

## Experience Goal

The task is not to create a news website, dashboard, content portal, productivity tool, or chatbot interface.

The task is to materialize the experience of orientation.

Users should feel:

- less chaos;
- less fragmentation;
- less cognitive overload;
- more clarity;
- more coherence;
- more understanding;
- more strategic calm.

## Homepage Principle

The homepage is not:

- a feed;
- a stream;
- an article wall.

The homepage is a map of meaningful signals.

## First Five Seconds

In the first five seconds, users should understand:

1. This is a calm orientation platform.
2. It helps identify what matters.
3. It connects AI, society, governance, human sustainability, and future signals.
4. It is governed and trustworthy.
5. It offers a next step, not more noise.

## Core Homepage Sections

1. Hero: "Portal for calm orientation in a complex world."
2. Daily Orientation: what matters now.
3. Meaningful Signals Map: structured signal clusters.
4. Orientation Object examples.
5. Trust Architecture: sources, confidence, AI disclosure.
6. AI Cabinet preview: governance-aware coordination layer.
7. For People / For Organizations.

## Orientation Object UX

Each object should visually contain:

- Signal;
- Context;
- Noise Level;
- Impact Horizon;
- Who Should Care;
- Systemic Effects;
- Next Orientation Step.

The user should not need to open a long article to understand why something matters.

## Daily Orientation Loop

The return habit is not dopamine. It is clarity.

Daily loop:

1. Morning orientation.
2. Top signals.
3. Noise versus significance.
4. Impact horizon.
5. Recommended next orientation step.
6. Long-term pattern memory.

## AI Cabinet Experience

AI Cabinet is not a chatbot.

It is:

- orientation engine;
- coordination layer;
- contextual intelligence system;
- governance-aware AI mediator.

User interaction should feel like guided reasoning, not prompt writing.

## Visual System

Design should feel European, calm, trustworthy, strategic, structured, and intelligent.

Use:

- whitespace over density;
- structure over decoration;
- typography-first identity;
- calm motion;
- layered navigation;
- maps and signals over feeds.

Avoid:

- chaotic dashboards;
- social media patterns;
- aggressive gradients;
- AI hype visuals;
- excessive density;
- prompt-heavy user interfaces.

## Final UX Test

Every screen must pass:

- Does this reduce chaos?
- Does this improve orientation?
- Does this increase clarity?
- Does this preserve human judgment?
- Does this reduce cognitive fragmentation?
