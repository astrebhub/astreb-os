# JAZEKKER Project Package

This folder is the working strategic source for JAZEKKER inside the AI Cabinet repository.

JAZEKKER is no longer framed as a conventional news site. It is an orientation-native civic intelligence system and the public layer of an Agentic Strategic Media Operating System.

Core formula:

```text
Noise -> Signals -> Context -> Orientation -> Trust -> Coordination -> Clarity
```

## Contents

- `00-email-cover-note.md` - short text for sending the package by email.
- `01-project-charter.md` - mission, principles, scope, AI role, and North Star.
- `02-agentic-media-operating-system.md` - target operating architecture.
- `03-orientation-experience-ux.md` - UX and product experience model.
- `04-execution-backlog.md` - execution backlog and first sprint.
- `05-placement-instructions.md` - placement and operating instructions.
- `06-mvp-specification.md` - concrete MVP scope, schemas, states, and implementation path.
- `deployment/` - safe deployment templates.
- `assets/` - visual references and concept images.

## Recommended Use

Use this package as a strategic source file for:

- product planning;
- website reorganization;
- repository restructuring;
- AI Cabinet media-runtime design;
- editorial governance;
- Trello or issue-board execution planning;
- investor, partner, and team briefing.

## Runtime Relationship

AI Cabinet is the governed runtime. JAZEKKER is the public intelligence surface.

No agent may publish, distribute, change durable strategy, change policy, or update strategic memory without the required approval record.
