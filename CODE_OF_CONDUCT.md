# Code Of Conduct

This project is for building governed AI infrastructure. Contributors are
expected to be direct, respectful, evidence-oriented, and careful with security
claims.

Unacceptable behavior includes harassment, doxxing, publishing secrets,
misrepresenting security guarantees, or encouraging bypasses of the governance
model.

Maintainers may remove comments, issues, pull requests, or contributors that
create security, privacy, or community risk.
